# 📝 Sistema de Gestión de Tareas

## 📚 Descripción del Proyecto
Este es un Sistema de Gestión de Tareas desarrollado con TypeScript vanilla y Vite. La aplicación permite a los usuarios organizar sus actividades diarias de manera eficiente mediante una interfaz limpia y moderna. Los datos se mantienen de forma local en el navegador del usuario utilizando `localStorage`, demostrando la aplicación de principios de arquitectura limpia y manipulación directa del DOM sin depender de frameworks de UI.

## ✨ Características Implementadas
* **Gestión Completa (CRUD):** Creación de tareas (título, descripción, categoría, prioridad), edición de estado (completada/pendiente) y eliminación de tareas.
* **Filtros Avanzados:** Capacidad de filtrar la lista de tareas por estado (completadas/pendientes) y por nivel de prioridad (Baja, Media, Alta).
* **Búsqueda en Tiempo Real:** Búsqueda dinámica de tareas por título.
* **Persistencia de Datos:** Uso de `localStorage` para guardar el estado de las tareas, evitando la pérdida de información al recargar el navegador.
* **Diseño Responsivo:** Interfaz adaptable a dispositivos móviles, tablets y computadoras de escritorio (Mobile First).
* **Modo Oscuro:** Estilos aplicados para una experiencia visual moderna y descansada.
